## 1. 읽는 순서와 우선순위
1. 화면 모양은 **피그마 노드**가 정답이에요. `screens.md`의 '최종 시안 목록' 표에 없는 프레임(v1, 비교판, 버린 후보)은 보지 않아요. 같은 이름의 옛 판이 있으니 노드 ID로만 찾아요.
2. 문서끼리 어긋나면 **나중 결정이 이겨요**. `screens.md`는 위에서 아래로 시간 순이고, 'Claude Code로 넘길 때' 절이 최종 요약이에요.
3. 이미 뒤집힌 결정(옛 문장이 문서에 남아 있음):
   - 2/4 고른 칩 '먹 채움' → **중간 강도**(회색 바탕 + 2px 먹 테두리 + 체크 + 굵은 글자). 3/4·글자 다듬기 프리셋 칩도 같은 모양.
   - 3/4 글씨 취향 '2열 칸·옅은 바탕' → **B: 쌍마다 두 칸을 한 줄로 붙인 양쪽 고르기**, 체크 오른쪽 위, 왼쪽 정렬. radiogroup 접근성은 지금 코드 그대로.
   - 가게 이야기 최소 '18자' → **10자**(`BUSINESS_MIN` 그대로) + 10~29자에 막지 않는 안내 한 줄.
   - 모바일 완성 띠 '써 보기' 보조 버튼 → **데스크톱만**. 모바일은 '폰트 받기' 폭 전체.
   - 오후 6차 규칙 ①(링크를 버튼 옆에) → **거둠**. '이름 바꾸기 · 즐겨찾기'는 버튼 줄 아래 왼쪽.
   - 글자 다듬기 '원래대로' 버튼(140) → **삭제**(프리셋 '원래대로'와 중복).
   - ST2·L2 '보류' → **v2로 확정**(549:402, 550:471).
   - 써 보기 '문구 입력 칸' → 따로 두지 않고 미리보기 판의 줄을 눌러 바로 고침. 데스크톱 '써 보기' 버튼은 섹션으로 내려가 첫 줄에 커서.
   - 모션: 메인에 화면 전환 코드가 있다는 문장은 틀림(코드에 없음). `motion.md` 정정본을 따라요.
4. 피그마 글꼴은 Noto Sans KR로 그렸지만 코드 본문 글꼴은 **SUIT 그대로**, 제목은 Black Han Sans. 시안의 '한결국수'·글자 그림은 자리 채움이에요.

## 2. 전체 규칙 (모든 화면)
- **바탕(A 규칙)**: 흰 바탕이 기본. 큰 민트 면은 ① 접수(메인 첫 화면, 질문 화면 접수증 바탕) ② 만드는 중(로고 읽는 중·차례 기다림·글자 그리기·파일 검사·빠진 글자 다시 그리기) ③ 완성 순간(스튜디오 첫 진입 완성 띠, 완성 메일)에만, 한 화면에 하나. 고르거나 정할 차례인 화면(견본 고르기, 기준 글자 확인, 멈춤·실패, 스튜디오 본문, 내 폰트)은 흰 바탕.
- 흰 바탕에 민트 글자·얇은 민트 선·민트 버튼 금지. 민트 위 글자는 늘 먹.
- 진행 막대는 DESIGN.md 2-2 그대로(먹 길 + 민트 채움).
- 스티커는 사실을 말할 때만.
- 말투는 해요체. 시간은 '느낌을 고른 뒤 12~17분'(FAQ·확인 창) / '약 15분'(스티커·메인) / 만드는 중은 서버 실제 남은 시간. 글자는 '한글 약 2,350자 + 숫자·문장부호·영문 대소문자 82자'. '무료'를 파는 말로 쓰지 않아요. 권리는 SIL OFL 1.1, 독점 아님.
- 접근성: 지금 코드의 aria·키보드 처리(radiogroup, roving tab, 확인 창 첫 초점 등)는 모양을 바꿔도 유지해요.

## 3. DESIGN.md에서 바꿀 것
- 2-4(테마 mint/50 · 띠 mint/100)를 거두고 위 'A 규칙'으로 바꿔요. `bg-bg-theme`·`bg-bg-theme-strong`을 쓰는 곳은 흰 바탕 또는 큰 민트 면(`bg-bg-brand`)으로 옮겨요.
- 8장 컴포넌트 표에 이번에 만든 공통 부품을 적어요.
- 모션 토큰 절을 새로 둬요(`motion.md` 3절).

## 5. 확인 방법 (키 없이)
- `npm run lint`, `npx tsc --noEmit`, `npm run build`가 통과해야 해요.
- 화면은 `npm run dev -- -p <포트>`로 띄우고 Playwright(설치돼 있음)로 1440·390 폭을 찍어 피그마 노드 스크린샷과 나란히 비교해요. 서버 키가 없어서 API가 필요한 화면은 Playwright `page.route`로 `/api/...` 응답을 임시 JSON으로 바꿔 상태별로 띄워요(형식은 `lib/types` 등 코드의 타입을 따름).
- `prefers-reduced-motion`을 켠 상태도 한 번 찍어요.

## 7. 키가 있는 곳에서의 마지막 확인 (용휘 님)
브랜치를 받아 `.env.local`과 엔진을 켠 뒤 폰트를 하나 실제로 만들어요. 이때 볼 것: 만드는 중 화면의 갱신(번호표 남은 시간, 글자 지도, 방금 그린 글자)과 깜빡임, 완성 순간 도장 반짝임(첫 방문에만), 스튜디오 써 보기·받기, 메일 네 가지.
