## 1. 한 줄 컨셉

**화면의 주인공은 사장님 가게의 글씨와 색이다. 로고체는 스티커처럼, 로고체가 일하는 자리에만 붙는다.**

- 화면 틀(버튼·입력·구분선)은 먹과 회색으로 물러나 있는다. 가게 로고 색은 시안(간판·메뉴판·포장·SNS)에만 나온다.
- 민트는 '로고체가 지금 무언가를 하고 있다/해냈다'는 자리에만 쓴다(2장). 그래서 민트가 보이면 늘 같은 뜻으로 읽힌다.
- 구조(내비게이션·폼·정보 위계)는 관습을 따르고, 컨셉은 색·글꼴 성격·시그니처 디테일에만 쓴다.

## 2. 색

토큰 원본은 `1103_컬러 토큰.md`. 화면 코드에는 **Semantic 토큰만** 쓴다(`bg-bg-canvas`, `text-text-primary` …). Primitive(`mint-400` 등)를 화면에 직접 쓰지 않는다.

### 2-1. 역할

| 역할 | 토큰 | 값 |
|---|---|---|
| 화면 바탕 | `bg/canvas` | white |
| 묶음·고른 행·옅은 칸 | `bg/surface` | neutral/50 #F6F6F5 |
| 무대(견본·로고를 놓는 바탕) | `bg/surface-strong` | neutral/100 #ECECEA |
| 글자 / 보조 글자 / 흐린 글자 | `text/primary` · `text/secondary` · `text/tertiary` | #141414 · #5E5E5B(6.5:1) · #7A7A77 |
| 구분선 / 칩·입력칸 테두리 | `border/default` · `border/strong` | #DDDDDA · #7A7A77(4.3:1) |
| 고른 칩·탭·행 테두리 | `border/active` | #141414 |
| **주 버튼** | `bg/inverse` + `text/inverse` | 먹 #141414 + 흰 글자 |
| 주 버튼 호버 | `bg/inverse-hover` **(새로 추가)** | neutral/800 #2E2E2D |
| B3 주 버튼 호버 | `bg/inverse-strong` (11/6) | black #000 (피그마 441:35) |
| 키보드 포커스 | `border/focus` | mint/700 #0A7558 (흰 바탕 5.7:1) |
| 통과·오류 | `text/success`·`text/error` 등 | green·red 계열 — 민트와 섞지 않는다 |

### 2-2. 민트를 쓰는 자리 (이 밖에는 쓰지 않는다)

| 자리 | 어떻게 |
|---|---|
| 진행 | 차오르는 버튼의 채운 부분, 진행 막대의 채움. **늘 먹 바탕 위에 민트**(10.9:1). |
| 지금 단계 | 단계 표시의 지금 단계 알약: `bg/brand` + `text/on-brand`(먹). |
| 완성 | 완성 도장 스티커(`CompletionStamp`, 11/6). 완성 순간의 큰 민트 면(2-4 ③). |
| 스티커 | 번호표·말풍선 형광펜·별 터짐 글자(8-0). 스티커는 사실을 말할 때만. |
| 로고·파비콘 | 로고 SVG 그대로(8장). |

- 흰 바탕 위 민트 면·선은 대비가 1.7:1이라 **경계로 쓰지 않는다**. 진행 막대도 흰 바탕에 바로 놓지 않고 먹 길(track) 위에 민트로 채운다(민트와 neutral/200 길은 1.2:1로 안 보인다).
- 민트 면 위 글자는 늘 먹. 흰 글자 금지.
- 흰 바탕에 민트 글자 금지. 민트 계열 글자가 필요하면 `text/brand`(mint/700).

### 2-4. 11/6 결정: 바탕 'A 규칙' (11/5 테마 mint/50 · 띠 mint/100을 거둔다)

- **바탕은 흰색(`bg/canvas`)이 기본이다.** 2-1의 '화면 바탕은 흰색'으로 돌아간다. body 바탕도 흰색(`globals.css`).
- **큰 민트 면(`bg/brand`, mint/400)은 세 순간에만, 한 화면에 하나만** 쓴다.
  1. 접수: 메인 첫 화면, 질문 화면의 접수증 바탕
  2. 만드는 중: 로고 읽는 중 · 견본 그리기 대기 · 글자 그리기 · 파일 검사 · 차례 기다림 · 빠진 글자 다시 그리기
  3. 완성 순간: 스튜디오에 처음 들어올 때 완성 띠, 완성 메일
- 사장님이 **고르거나 정할 차례인 화면**(견본 고르기, 기준 글자 확인, 멈춤·실패, 스튜디오 본문, 내 폰트)은 흰 바탕이다.
- 민트 위 글자는 늘 먹이다. 흰 바탕에 민트 글자·얇은 민트 선·민트 버튼은 쓰지 않는다.
- 진행 막대는 2-2 그대로(먹 길 + 민트 채움).
- `bg/theme`(mint/100)·`bg/theme-strong`(mint/200) 토큰은 11/6에 모든 화면에서 거뒀다(사용처 0). 값만 남겨 두고 새 코드에는 쓰지 않는다.
- 이유(11/6, screens.md '결정했던 것의 근거'): mint/50 바탕은 흰색과 거의 구분이 안 되고 흰 카드만 상자처럼 생긴다. mint/100 띠와 진한 민트가 한 화면에 있으면 두 색으로 읽히고 지금 단계 알약이 흐려진다.

### 2-3. 예전 변수 → 새 토큰

`1103_컬러 토큰.md`의 대응표를 따른다. 11/3 결정으로 '정할 것'이었던 칸은 이렇게 정했다.

- `bg-ink` 주 버튼 → `bg/inverse` + `text/inverse`, 호버 `bg/inverse-hover`.
- `bg-ink` 진행 막대 채움 → 길은 `bg/inverse`, 채움은 `bg/brand`.
- `--accent` 파랑(꼬리표 점·단계 표시) → 지금 단계는 `bg/brand`, 꼬리표 점은 `text/secondary`. 파랑은 브랜드에서 뺀다.
- 크림 `--paper` → `bg/canvas`(흰색). 카드와 바탕이 같은 흰색이 되므로 카드는 상자 대신 구분선·여백으로 나눈다(4장).

| 쓰임 | 글꼴 | 불러오기 |

## 4. 레이아웃·간격

- **최대 폭**(11/6 저녁: 화면마다 76rem·72rem으로 달라 머리줄 로고와 본문 왼쪽 끝이 어긋났다): 머리줄과 모든 화면 본문이 같은 `max-w-page`(globals.css `--container-page`, 215/3rem)를 쓴다. 1,024px부터 1rem = 18px이라 1,440 화면에서 본문 1,200px, 왼쪽 끝 120px(피그마와 같음).
- **옆 여백**: 휴대폰은 화면마다 지금 값 그대로(머리줄·메인·스튜디오·목록 `px-4`, 만드는 중·느낌 고르기 `px-5`), `lg` 이상은 모두 `px-10`(2.5rem). 폭과 옆 여백을 화면마다 따로 정하지 않는다.
- **간격**: 4px 단위. 자주 쓰는 값 8·12·20·28 (`gap-2`·`gap-3`·`gap-5`·`gap-7`). 같은 묶음 안은 8–12, 묶음 사이는 20–28.
- **나누기**: 상자 대신 선과 여백. 카드 테두리·그림자로 영역을 나누지 않고 `border/default` 구분선과 간격으로 나눈다. 상자 안에 상자를 두지 않는다.
- **큰 화면**(11/5 확대 시험): 1,024px부터 html 글자 크기를 112.5%로, 1,800px 125%, 2,100px 137.5%, 2,500px 150%, 2,900px 162.5%로 키워 비율 그대로 커진다.

## 6. 라운드·그림자

지금 8가지 → 4단계로 줄인다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `rounded-full` | — | 버튼, 칩, 입력칸, 알약, 토글, 떠오르는 막대 |
| `rounded-[1.25rem]` (lg) | 20px | 무대·시안, 로고 올리는 칸, 모달, 받기 메뉴 |
| `rounded-[0.875rem]` (md) | 14px | 글자 칸, 작은 상자, 목록 상자 |
| `rounded-[0.625rem]` (sm) | 10px | 메뉴 항목, 작은 글자 썸네일 |

- `rounded-2xl`(16)·`rounded-xl`(12)·`rounded-lg`(8)는 고칠 때 위 단계로 옮긴다. 진행 막대의 `rounded-sm`은 막대 끝 처리라 예외.
- **그림자는 떠 있는 층에만**: 떠오르는 막대, 받기 메뉴, 모달. 값 하나 `0 12px 32px rgba(20,20,20,.16)`. 카드·무대에는 쓰지 않는다. 로고 다이컷의 그림자는 로고 SVG 안에만 있다.
- 스티커(번호표·도장·말풍선·별 터짐)의 칼선 그림자는 예외로 스티커 안에만: `--sticker-shadow`·`--stamp-shadow`·`--burst-shadow`(globals.css, filter 값).

## 6-1. 모션 (11/6, `docs/design-1106/motion.md`)

시간·곡선은 토큰으로만 쓴다(`globals.css`).

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--dur-fast` | 100ms | 버튼 누름(0.97배), 체크 |
| `--dur-base` | 200ms | 바뀐 안쪽 내용 들어오기, 닫힘, 번호표 숫자 넘김, 떠오르는 막대 |
| `--dur-move` | 300ms | 막대 너비, 아래 창·서랍 열림 |
| `--dur-moment` | 600ms | 완성 도장 빛 한 번(여기에만) |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 기본 (`ease-standard` 유틸리티) |
| `--ease-enter` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 나타나기·열기 (`ease-enter`) |
| `--ease-exit` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 사라지기·닫기 (`ease-exit`) |

- 쓰는 법: `duration-(--dur-base) ease-enter`, 나가는 쪽은 들어오는 쪽보다 짧게(열림 300 / 닫힘 200).
- 키프레임 유틸리티: `animate-ds-stick`(스티커 '붙기': 1.06배·−2° → 1배·원래 각도 `--sticker-rot`, 240ms, 처음 한 번) · `animate-ds-enter`(6px 아래에서 200ms) · `animate-ds-check`(체크 원 톡 150ms, `--dur-check`) · `animate-ds-roll`(번호표 숫자 세로 넘김 200ms) · `animate-ds-pop-glyph`(방금 그린 글자 300ms) · `animate-ds-pop-menu`(받기 메뉴 200ms) · `animate-ds-rise`(떠오르는 막대 200ms). 완성 도장 빛 한 번은 `CompletionStamp shine`.
- 움직이는 건 `transform`·`opacity`만. 마우스를 올렸을 때만 생기는 효과(B3 화살표 2px, 도장 빛 따라가기)는 `(hover: hover)` 기기에서만(Tailwind `hover:`가 이미 그렇다).
- **움직임 줄이기**: 옮겨 가거나 커지는 움직임은 끄고 투명도·색만 남긴다. 위 유틸리티에 `ds-motion` 클래스를 같이 붙이면 키프레임이 '투명도만'으로 바뀌어 남고, 붙이지 않은 요소는 예전처럼 거의 0초가 된다. 도장 빛은 멈춘 한 줄로. 로딩 표시(돌기·막대 왕복)는 지금 규칙 그대로(WCAG 2.2.2 예외).
- 하지 않는 것: 민트 바탕 패턴·흐름, 스티커 둥실둥실, 패럴랙스, 커서 따라다니기, 카운트업, 꽃가루, 화면 전환 API(`::view-transition-*` 규칙은 11/6에 지웠다).

## 7. Do's and Don'ts

**Do**
- 화면마다 먹 채움 주 버튼은 하나.
- 고른 칩·탭·행은 2px 먹 테두리 + 체크(채우지 않는다).
- 비활성은 색만 흐리게 하지 않고 점선 테두리와 이유 문구로도 알린다.
- 진행은 먹 바탕 위 민트, 완성은 민트 스티커 — 로고체가 일하는 자리는 늘 같은 모양.
- 시안·글자 그림은 실제 폰트로 그린다(AI가 그린 그림을 글자 대신 쓰지 않는다).
- 시간이 흐르면 넘어가는 화면은 멈출 수 있게 한다(WCAG 2.2.1, '기다리기').

**Don't**
- 민트 주 버튼, 민트 토글, 민트 링크.
- 흰 바탕 위 민트 글자·얇은 민트 선.
- 크림 바탕, 명조, 코럴, 보라 그라데이션, 빛나는 효과, 이모지 이름표, 대문자 자간 넓힌 이름표.
- 카드 안에 카드, 테두리와 그림자를 같이 쓴 상자.
- 가게 로고 색을 화면 틀(버튼·머리줄)에 쓰기 — 가게 색은 시안 안에만.
- 어두운 모드 토큰을 화면에 섞어 쓰기(9장).
